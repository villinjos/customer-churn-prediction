# Customer Churn Prediction

## Project Overview

This project uses Machine Learning to predict customer churn based on customer behavior and historical data.

## Business Problem

Customer retention is critical for business growth. This project helps identify customers who are likely to leave so that retention strategies can be applied proactively.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
